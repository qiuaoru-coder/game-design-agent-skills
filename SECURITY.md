# Security Policy / 安全说明

## Supported version / 支持范围

Security fixes are applied to the latest version on the default branch. Older copies and downloaded packages may not receive separate fixes.

安全修复以默认分支上的最新版本为准。旧版本副本和已下载的历史压缩包不保证单独修复。

## Report a vulnerability privately / 私密报告安全问题

Please do not disclose a suspected vulnerability in a public Issue, Discussion, or pull request.

Use GitHub's private vulnerability reporting page:

https://github.com/qiuaoru-coder/game-design-agent-skills/security/advisories/new

请不要通过公开 Issue、Discussion 或 PR 披露疑似安全漏洞。请使用上面的 GitHub 私密漏洞报告页面。

Include, when possible:

- A clear description of the issue and potential impact.
- Affected files, versions, or commit hashes.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.
- Whether the report contains sensitive information.

如条件允许，请提供：

- 问题描述及可能影响。
- 受影响的文件、版本或提交。
- 复现步骤或最小验证示例。
- 可行的缓解建议。
- 报告中是否包含敏感信息。

Please allow time for the report to be reviewed before public disclosure. This channel is for security vulnerabilities; ordinary skill feedback and feature ideas should use the repository's Issue forms.

请在公开披露前预留处理和沟通时间。该渠道仅用于安全漏洞；普通 Skill 反馈和功能建议请使用仓库的 Issue 表单。
